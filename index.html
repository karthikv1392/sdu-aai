Resource library

Foundational papers

  • Vaswani et al. — Attention Is All You NeedThe Transformer architecture underlying every LLM used this week
  • Yao et al. — ReAct: Synergizing Reasoning and ActingThe reason-act loop most agent frameworks build on
  • Schick et al. — ToolformerTeaching LLMs to call tools on their own
  • Lewis et al. — Retrieval-Augmented GenerationDay 3's RAG spotlight paper, in full

Frameworks & protocols

  • Model Context ProtocolOpen standard for connecting agents to tools and data
  • Agent2Agent (A2A) ProtocolInteroperability between agents across vendors
  • Google Agent Development KitMulti-language framework for building and deploying agents
  • LangGraphGraph-based orchestration for multi-agent workflows
  • CrewAIRole-based multi-agent framework
  • Microsoft AutoGenConversation-driven multi-agent framework
